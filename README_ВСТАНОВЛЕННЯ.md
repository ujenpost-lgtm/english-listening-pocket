# English Pocket 16.0 — A2+ → B1

**Наша ціль:** від перехідного A2+ до впевненого B1 через щоденне читання, невеликі порції корисних фраз, активне пригадування та зрозумілі відео.

## Що нового

- **«Слова» → «Навчання».** Один безперервний цикл: 3, 5, 7 або 10 нових карток (типово 5) → пояснення й озвучування → вправи саме з цими фразами → мінітест → ще одна спроба для помилок → інтервальне повторення.
- **Пріоритет A2+–B1.** Нова добровільна добірка із 32 фраз із повсякденного життя, роботи, транспорту, магазинів і побутових ситуацій. Нові базові фрази в черзі стоять перед складнішими; старі картки не стираються.
- **Повторення старого перед новим.** Якщо є картки, термін повторення яких настав, у розділі «Навчання» з’являється проста кнопка «Спочатку повторити».
- **Озвучування.** Англійські картки, приклади та виділений текст у читалці озвучуються через синтезатор мовлення браузера — без платних ключів або AI API. Якість голосу залежить від пристрою; на деяких телефонах потрібно мати встановлений англійський голос.
- **Відео.** Тепер підібрано A2/B1, зокрема конкретні відеоуроки British Council і курс VOA Level 1. B2 не включено до рекомендованого маршруту.
- **Читалка та словник.** Залишилися EPUB/TXT/HTML, повноекранне читання, свайпи, компактна панель для слова/фрази, закладки, бібліотека, SRS, JSON-імпорт/експорт. Наявні ключі сховища не перейменовувалися.

## Як оновити через GitHub Pages

1. **Спочатку збережи повну резервну копію.** У поточному English Pocket відкрий ⚙ → «Зберегти все». Перевір, що JSON завантажився. Збережи його окремо від ZIP оновлення.
2. Завантаж `English_Pocket_16_0_GitHub_Pages.zip` і розпакуй. Переконайся, що всередині у корені є `index.html`, `app.js`, `learning_reader15.js`, `learning_level16.js`, `a2_b1_cards.js`, `starter_cards.js`, `pako.min.js`, `sw.js`, `manifest.webmanifest` та іконки.
3. Відкрий свій репозиторій `https://github.com/ujenpost-lgtm/english-listening-pocket`.
4. У кореневій папці публікації заміни файли попередньої версії на файли з ZIP. У GitHub можна скористатися **Add file → Upload files**; для однойменних файлів за потреби використовуй локальний Git чи редактор GitHub. Не завантажуй ZIP як один файл — завантаж його вміст.
5. Зроби **Commit changes**. Відкрий `https://ujenpost-lgtm.github.io/english-listening-pocket/` і перевір номер **16.0** унизу сторінки.
6. Якщо відображається попередня версія: закрий усі вкладки застосунку, відкрий сайт повторно або перезавантаж сторінку. Service worker застосує нові файли після оновлення кешу. **Не видаляй дані сайту**, перш ніж перевіриш резервну копію.

## Перший запуск

1. У «Слова» натисни **«Додати базову добірку A2+–B1»** (якщо власні слова вже є) або **«+ 32 практичні фрази A2+–B1»** (якщо словник порожній).
2. Натисни **«Вивчити 5 фраз»**. Прослухай кожну, побач значення, потім відтвори фрази у практиці й тесті.
3. На наступному занятті спершу відкрий **«Спочатку повторити»**, якщо вона є. Не намагайся наздоганяти пропущені дні.
4. У «Читати» додай власну EPUB-книгу (без DRM); натисни слово або виділи фразу. Внизу з'явиться невелика панель. Якщо українського перекладу ще немає, введи його сам або за своїм бажанням відкрий зовнішній перекладач із цієї панелі.
5. У «Відео» почни з рівня **A2** — короткі вправи з BBC/VOA/British Council. Для онлайн-відео потрібен інтернет.

## Обмеження

- Це **локальний PWA-застосунок**. Книги й словник зберігаються у браузері на конкретному пристрої; між пристроями немає автоматичної синхронізації. Регулярно роби повний JSON-експорт.
- Для створення **нових перекладів довільних речень** немає вбудованої AI-моделі чи автоматичного перекладу. Уже збережені значення показуються локально. Зовнішній Google Translate відкривається тільки за натисканням користувача.
- Перевірка введених фраз порівнює їх із написанням на картці. Якщо інша форма теж правильна, можна **самостійно** зарахувати відповідь; автоматичної граматичної оцінки немає.
- Рівні A2+/B1 у вбудованій добірці — **навчальні орієнтири**, а не результат стандартизованої сертифікації кожної фрази.
- Тести навчального циклу виконані на мобільному розмірі в Chromium із тестовою сторінкою; це **не замінює** тестування Safari/Chrome на реальному телефоні. Озвучування і EPUB-свайпи варто перевірити після встановлення.

## Тест після оновлення

- [ ] Існуючі книги та словник відображаються.
- [ ] Нова добірка з 5 карток проходить 3 етапи й завершується SRS.
- [ ] Озвучування англійських карток працює на телефоні.
- [ ] Свайп у EPUB змінює сторінку.
- [ ] Виділення фрази показує компактну панель, не перекриваючи всю книгу.
- [ ] Експорт «Зберегти все» завантажує JSON із поточними картками.
