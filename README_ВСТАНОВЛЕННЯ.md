# English Pocket 20.0 — інструкція оновлення

## Що отримуєш

Одну PWA з трьома вкладками — **Читати, Слова, Відео** — для поступового переходу від A2+ до B1. Словник, EPUB/TXT/HTML-книги, результати навчання та закладки зберігаються локально.

## Як оновити GitHub Pages

1. **Спочатку відкрий поточну версію** на `https://ujenpost-lgtm.github.io/english-listening-pocket/`.
2. Перейди в **⚙ → Зберегти все** і завантаж повну резервну копію JSON. Збережи її окремо від телефона. Копія включає картки, історію SRS, книги і закладки.
3. Завантаж `English_Pocket_20_0_GitHub_Pages.zip` та **розпакуй** архів. Завантажувати ZIP у репозиторій як один файл не можна — потрібні окремі файли з архіву.
4. Відкрий репозиторій `https://github.com/ujenpost-lgtm/english-listening-pocket`.
5. Замінюй файли на тій гілці й у тій папці, з якої GitHub Pages бере сайт (зазвичай корінь основної гілки). Залиши всі JS, CSS, manifest, service worker, іконки та `pako.min.js` разом.
6. Натисни **Commit changes**. Після оновлення GitHub Pages знову відкрий сайт. Перевір, що внизу сторінки вказано **20.0**. Якщо показує стару версію, закрий і відкрий PWA або онови сторінку; іноді service worker ще тримає старий кеш.
7. Перевір свої книги, картки та позиції. **Не імпортуй копію повторно, якщо дані залишилися на місці**, щоб не породжувати плутанину з версіями.

## Як навчатися щодня

- **Слова → Навчання**: угорі компактний план; повтори старе, потім 3–5 нових карток. Пройди практику і тест.
- **Слова → Додаткова практика**: контекст, диктант, вимова, аудіоповторення і власні речення працюють із пройденим матеріалом.
- **Слова → Діалоги з життя в Канаді**: обери ситуацію. Якщо потрібних реплік ще немає, натисни «Додати репліки до навчання». Вивчи перші дві у звичайному навчальному циклі; тоді відкриється початок послідовного діалогу. Для повного діалогу послідовно пройди всі фрази.
- **Читати**: відкрий EPUB, перегортай свайпом. Натисни слово або виділи фразу; переклад відображається в нижній панелі. Озвучування — кнопкою 🔊. Підкреслюються лише пройдені фрази; перемикач знаходиться в налаштуваннях читання.
- **Відео**: кнопка «Показати уроки Bob» і мініпрактика після перегляду.

## Важливі обмеження

- **Автоматичний переклад** — через безплатний зовнішній сервіс MyMemory за згодою користувача. Потребує інтернету; іноді може не працювати або давати неточний переклад. Локальний словник не перекладає гарантовано всі речення.
- **Діалоги** — підготовлені сценарії, не AI-співрозмовник. Відповідь перевіряється на потрібну вивчену фразу. Вільну граматику програма об'єктивно не оцінює.
- **Адаптивне повторення** — наша евристика на базі історії відповідей, а не повноцінний FSRS з оптимізацією параметрів на великій історії.
- **Озвучування** залежить від голосів браузера; мікрофон потребує дозволу та HTTPS.
- **Повноцінне тестування на фізичному телефоні** ще потрібне. Автоматизовані тести проводилися у Chromium з тестовим сховищем, а не на твоєму пристрої.
- **Правила оренди, банківські вимоги, медицина й транспорт** залежать від провінції, установи та міста. Сценарії навчають природної англійської, але не замінюють консультації.

## Захист даних

Періодично відкривай **⚙ → Надійність даних → Перевірити дані / Зберігати дані на пристрої**. Запит на постійне сховище знижує ризик автоматичного очищення браузером, але не замінює експорт повної резервної копії.
