# English Pocket 20.1 — як безпечно оновити

Це виправлення версії 20.0, зосереджене на **моїх картках** та **контекстному пригадуванні**.

## Оновлення на GitHub Pages

1. У поточному застосунку відкрий **⚙ → Зберегти все** та збережи повну резервну копію JSON.
2. Завантаж `English_Pocket_20_1_GitHub_Pages.zip` і розпакуй.
3. Відкрий GitHub-репозиторій `ujenpost-lgtm/english-listening-pocket` та завантаж усі файли з архіву в корінь папки публікації GitHub Pages. Підтвердь заміну старих файлів і натисни **Commit changes**.
4. Відкрий https://ujenpost-lgtm.github.io/english-listening-pocket/ і перевір, що в назві або внизу сторінки написано **20.1**. Якщо відображається 20.0, перезавантаж сторінку; у встановленому PWA за потреби закрий і відкрий застосунок знову. **Не очищуй дані сайту**, якщо немає резервної копії.
5. Перейди **Слова → Навчання → Вивчити 5 фраз**. Нові картки тепер вибираються з особистих карток у порядку додавання. Далі перевір етап **Тренування** та відкрий **🎧 Додаткова практика → Контекст**.

## Важливі правила

- Наявні готові добірки та канадські репліки **не видаляються** зі словника, але більше не домішуються в нові уроки без твоєї явної дії.
- Якщо хочеш вивчати конкретну готову репліку: **Мої картки → відкрити картку → «Додати до моїх уроків»**.
- Якщо у картці є приклад на кшталт `I came across an interesting book.`, вправа покаже `I ________ an interesting book.` та українське значення. Зараховуються форма з прикладу та словникова форма.
- Якщо у картці немає англійського прикладу, програма **не вигадує його**. Додавай контекст через редагування картки.
- Незавершений урок із шаблонними картками може бути автоматично перебудований і початися заново. Словник і вже отримані SRS-результати від цього не стираються.
- Імпортовані картки з порожнім SRS тепер спочатку **вивчаються**, а не помилково вважаються раніше вивченими.
- Усі дані зберігаються в браузері. Регулярно роби повну резервну копію.

## Перевірка на телефоні

Насамперед перевір: (1) порядок нових карток; (2) наявність контексту в тренуванні; (3) правильне відтворення `come across` / `came across`; (4) збереження SRS після перезавантаження. Якщо якась картка не має прикладу в словнику, контекст створено не буде — це не помилка відображення.
