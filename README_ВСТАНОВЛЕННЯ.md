# English Pocket 18.1 — встановлення та використання

## Що змінилося

- **Оформлення**: стримана темно-синя тема за замовчуванням, світло-блакитна тема в ⚙ → Оформлення.
- **Слова**: лише «Навчання» та «Мої картки». Окремий великий контроль прогресу й короткі канадські фрази приховані. Додаткова практика — у згортаному блоці.
- **Практика**: лише картки, завершені в навчальному циклі, а не всі імпортовані чи збережені слова. Після вивчення → практика/тест → SRS; у додаткових тренуваннях беруть участь тільки пройдені картки.
- **Почати заново**: окрема картка — «Мої картки» → натисни на картку → «Вивчити заново». Усі результати — ⚙ → «Почати вивчення заново» → підтвердити двічі. Англійські фрази, переклади, приклади й книги зберігаються.
- **Канада**: діалоги використовують **лише вивчені тобою фрази**. Обери тему (житло, аптека, робота, кафе, транспорт, банк, знайомство або загальна розмова). Відповідай англійською; перевіряється наявність потрібної фрази, не вся граматика.
- **Читалка**: чотири основні дії в меню, решта в «Aa Шрифт і вигляд». Переклад у компактній панелі, без відкриття окремого вікна картки.

## Переклад — важливі умови

1. Знайомі слова та фрази перекладаються миттєво **локально** (власні картки + мінісловник).
2. Для нових слів, фраз чи речень натисни «Перекласти». Першого разу застосунок запитає згоду на надсилання виділеного тексту до **MyMemory** (безплатний зовнішній перекладацький API). Без згоди нічого не надсилається.
3. Після згоди невідомі фрагменти перекладаються **автоматично в самій нижній панелі**, якщо інтернет і сервіс доступні. Результати кешуються на пристрої; переклад можна виправити перед збереженням картки.
4. Без інтернету, при ліміті чи помилці сервісу відображається повідомлення й кнопка зовнішнього перекладу. Словник, книги, картки та повторення працюють офлайн.
5. Безплатний MyMemory має обмеження (зокрема до 500 байтів одного сегмента й приблизно 5000 символів на день анонімно). Довші виділення діляться на сегменти до 440 байтів; надто довгий текст попросить зменшити виділення.
6. Перекладацький сервіс не є платним AI API; його відповіді можуть бути неточними. Для приватних текстів не вмикай онлайн-переклад.

## Оновлення на GitHub Pages

1. Відкрий поточну версію застосунку за постійною адресою. Натисни **⚙ → Зберегти все**. Збережи JSON окремо на телефоні/комп'ютері. За можливості збережи також ZIP поточної версії GitHub.
2. Завантаж `English_Pocket_18_1_GitHub_Pages.zip` та розпакуй його.
3. Відкрий [github.com/ujenpost-lgtm/english-listening-pocket](https://github.com/ujenpost-lgtm/english-listening-pocket). У папці, яку використовує GitHub Pages, **заміни** старі файли вмістом нового ZIP. Не клади всі файли в додаткову вкладену папку.
4. Натисни **Commit changes**. Дочекайся завершення GitHub Pages Deploy (GitHub → Actions).
5. Перейди на [English Pocket](https://ujenpost-lgtm.github.io/english-listening-pocket/). У футері повинно бути «18.1».
6. Якщо ще показує 18.0, закрий усі вкладки/PWA, знову відкрий сайт і перезавантаж сторінку — оновлюється кеш service worker.
7. Перевір свої старі книги та картки. **Не імпортуй резервну копію без потреби**: звичайне оновлення за тією самою адресою не має видаляти локальні дані. Якщо даних немає, імпортуй збережений JSON через ⚙.

## Перевірки перед щоденним використанням

- Книги: перегорнути дві сторінки свайпом і повернутися до збереженої позиції.
- Переклад: виділити нове речення → надати згоду → дочекатися перекладу в панелі → зберегти в словник.
- Слова: пройти заняття, перевірити додаткову практику, відкрити канадський діалог.
- Скидання: на тестовій картці натиснути «Вивчити заново» і переконатися, що текст не зник.

**Обмеження тестування:** синтаксис JavaScript, згортання меню, вибір тільки вивчених карток, скидання через кнопку та перекладацький механізм з імітованою відповіддю API перевірені в Chromium. Реальну відповідь MyMemory, EPUB-свайпи та озвучування на фізичному Android/iPhone ще необхідно перевірити.
