# English Pocket 27.0.0 — встановлення та перший запуск

## Найперше: збережи навчальні дані

У поточній версії 26.1 відкрий **⚙ → Data Vault → Повна копія**. Перевір у папці **Завантаження**, що JSON-файл створений і не має нульового розміру. За потреби окремо збережи особливо важливі голосові записи. **Не очищай сховище браузера й не видаляй встановлений застосунок.**

## Через GitHub Desktop

1. Завантаж і розпакуй ZIP версії **27.0.0**.
2. Відкрий GitHub Desktop, вибери `english-listening-pocket`, гілка `main`.
3. Натисни **Repository → Show in Explorer**.
4. У розпакованому архіві вибери всі файли (`Ctrl+A`, `Ctrl+C`) і встав безпосередньо до папки репозиторію (`Ctrl+V`). Підтверди заміну збіжних файлів. Не видаляй `.git`.
5. У GitHub Desktop введи Summary: `English Pocket 27.0 Warm Paper` → **Commit to main** → **Push origin**.
6. Дочекайся завершення GitHub Pages, потім перевір адресу: https://ujenpost-lgtm.github.io/english-listening-pocket/version.txt — там має бути `English Pocket 27.0.0`.
7. Відкрий https://ujenpost-lgtm.github.io/english-listening-pocket/ і перевір книжки, картки та SRS **до очищення будь-яких даних**.

## Де новинки

- **Warm Paper** — новий вигляд за замовчуванням; нічний варіант у ⚙.
- **Мовна ДНК** — вкладка **Слова → Мовна ДНК** (розгортаний блок, тільки вивчені картки).
- **Living Stories** — **Слова → Закріплення → Історії → Living Stories**. Сюжет змінюється за рішенням після виконання вправи. Збережено й попередні історії.
- **Pocket Walk** — **Слова → Pocket Walk**. Натисни «5 фраз» або «10 фраз»; прослуховування НЕ додає автоматично успіхів у SRS.
- **Canada Quest** — **Відео → Canada Quest**. Короткі мовні ситуації, власна відповідь, самоперевірка, за бажанням запис.
- **Мій навчальний маршрут** — **Відео → Мій навчальний маршрут** (компактні 4 кроки). Усі попередні відеоуроки залишаються.

## Що з Echo?

**Echo не додано**, як ти й попросив. Звичайна функція Speaking Studio зі старих версій зберігається.

## Що перевірити на телефоні

1. Три основні вкладки; Warm Paper і нічний перемикач.
2. Старі книги/картки/вивчені фрази й навчальний прогрес.
3. Проходження одного сюжетного вибору та повернення до попереднього епізоду.
4. Canada Quest: відповідь і перехід до наступного завдання.
5. Pocket Walk: чи є український голос та чи не зупиняється озвучування на телефоні.
6. **Data Vault → Повна копія** після встановлення.

**Увага:** дані різних користувачів на різних пристроях залишаються незалежними. Без хмарної синхронізації. Тривала робота TTS при блокуванні екрана залежить від браузера.
