# English Pocket 18.0 — встановлення і використання

**Версія:** 18.0 · **Навчальний маршрут:** A2+ → B1 · **Основні вкладки:** Читати / Слова / Відео. Жодних платних AI API.

## Оновлення поточного сайту GitHub Pages

1. Перед будь-якою заміною відкрий свою поточну версію English Pocket, натисни **⚙ → «Зберегти все»** та збережи **повний JSON-файл** на пристрої. Переконайся, що файл існує. Він може бути великим, оскільки включає книги.
2. Завантаж **English_Pocket_18_0_GitHub_Pages.zip**, розпакуй його. В корені розпакованого каталогу мають бути `index.html`, `app.js`, `learning18.js`, `sw.js`, `manifest.webmanifest` та інші файли.
3. Відкрий GitHub-репозиторій `https://github.com/ujenpost-lgtm/english-listening-pocket` і перевір, з якої гілки й папки публікується сайт (**Settings → Pages**).
4. У публікаційній папці онови файли **вмістом** ZIP, зокрема `index.html`, `app.js`, `learning18.js`, `sw.js` і `manifest.webmanifest`. **Не завантажуй ZIP як єдиний файл.** Збережи зміни кнопкою **Commit changes**.
5. Після оновлення GitHub Pages відкрий `https://ujenpost-lgtm.github.io/english-listening-pocket/` та перевір нижній напис **English Pocket 18.0**. Якщо видно стару версію, закрий PWA та відкрий знову або перезавантаж сторінку. **Не очищуй дані сайту**, адже це може видалити локальні книги й словник.
6. Перевір кілька важливих дій: відкрий EPUB і гортай свайпом; натисни на слово, переглянь локальну підказку; у «Слова» відкрий «Додаткова практика»; у «Відео» знайди «Bob the Canadian».

Для встановлення PWA вперше: **Android/Chrome:** меню ⋮ → «Встановити застосунок» / «Додати на головний екран». **iPhone/Safari:** «Поділитися» → «На початковий екран» → «Додати». Використовуй HTTPS-посилання на GitHub Pages, а не локальний HTML.

## Вкладка «Слова»

- Головний цикл збережено: **спочатку повтори належні картки, потім вивчи 3–5 нових → практика → тест → повторення складного**. Фрази з книги та рівня A2+–B1 мають пріоритет.
- Додаткові методи знаходяться в **одній згорнутій секції «Додаткова практика»**. Вони використовують картки поточного уроку, а якщо уроку немає — картки, що потребують повторення, та зі збереженими прикладами.
- **Контекст:** доповни фразу або відтвори її за українським значенням.
- **Диктант:** прослухай і набери почуте; англійський текст до перевірки приховано.
- **Вимова:** прослухай зразок, запиши себе, прослухай обидва записи. Мікрофон працює лише з дозволу та в захищеному контексті HTTPS. Записи не передаються на сервер.
- **Канадські діалоги:** 5 підготовлених сценаріїв. Вибір природної репліки, виправлення після помилки, озвучування та додавання до карток.
- **Перевірка прогресу:** 8 завдань, рекомендовано раз на 2 тижні. Результат не є підтвердженням CEFR B1, а відображає прогрес саме в цих вправах.

## Вкладка «Читати»

- Відкривай EPUB/TXT/HTML без DRM, читай повноекранно, гортай свайпом. Працюють налаштування шрифту, пошук, закладки та озвучування абзацу чи сторінки.
- Виділи слово, фразу або речення. Компактна панель покаже збережений переклад або локальну підказку для типових A2–B1 виразів. **Значення неоднозначних слів перевіряй за контекстом**; їх можна виправляти вручну.
- Якщо перекладу немає, можна відкрити зовнішній перекладач окремою кнопкою. Повністю автоматичний переклад нових довільних речень без сервісу не підтримується.

## Вкладка «Відео»

- Є Bob the Canadian, British Council, VOA, BBC. Відео відкриваються у першоджерелі; потрібне підключення до інтернету.
- Після вибраного ролика натисни **«Практика»**: завдання перед переглядом, питання після, коротка нотатка англійською та збереження власної фрази (з перекладом) у картки.
- Додано перевірені уроки: «Around the House» (`WHYMGNbPv2U`), «Ordering Food» (`uUMPULuwdLI`), «About Canada» (`Ikc7jHLgHBo`).

## Резервне копіювання та відновлення

Експорт **⚙ → «Зберегти все»** включає книги, картки з історією повторень, прогрес, відеопозначки, нові результати вправ `elp-18-*` та налаштування. Після імпорту на інший пристрій нові ключі відновлюються, якщо відповідні дані ще не існують, а наявні картки й книги не перезаписуються. Не видаляй поточні дані, доки не перевіриш копію.

## Відомі технічні обмеження

- Ніякого AI/онлайн-перекладацького API у фоні немає. Вільний текст і вимова **не оцінюються автоматично**.
- Доступність голосів і запису залежить від браузера. Для мікрофона потрібен дозвіл користувача.
- У тестовому Chromium перевірено сценарії на основі ізольованого HTML із тестовим сховищем. Роботу після публікації через GitHub Pages, збереження книг після реального оновлення PWA та фізичний Android/iPhone ще потрібно перевірити.
