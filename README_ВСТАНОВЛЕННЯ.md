# English Pocket 23.0 — встановлення і короткий посібник

**Основа:** English Pocket 22.1. **Рівень:** A2+ → B1. Три вкладки: Читати · Слова · Відео.

## Що нового

1. **Великий англо-український словник офлайн** — у ⚙ → «Великий словник офлайн» можна імпортувати оригінальний ZIP словника `en-uk` від koreader-dicts. Після імпорту записи і словоформи зберігаються локально в IndexedDB. Вбудований короткий словник 22.1 працює відразу, без цього кроку. Великий ZIP **не входить до пакета**: його потрібно один раз завантажити зі сторінки автора.
2. **Словник у контексті** — якщо у слова декілька українських значень, у компактній панелі можна вибрати потрібне. Для кількох поширених багатозначних слів є перевірені приклади вживання. Твоя власна картка має пріоритет над загальним словником. Це не повноцінний перекладач довільних речень.
3. **Shadowing у читалці** — меню ☰ → «🎙 Слухай і повторюй». Слухай коротке речення поточної сторінки, повторюй уголос, переходь до наступного. Голос — обраний раніше у ⚙. Користувач контролює темп, автоматичної оцінки вимови немає.
4. **Лексика книги** — меню ☰ → «Aa Текст» → «Слова з розділу». Додаток вибирає поширені у розділі слова, яких немає у твоїх картках, із підказками локального словника. **Нічого не додається без натискання ＋.** Після додавання фраза проходить звичайний цикл навчання.
5. **Розділ → закріплення** — на завершальній сторінці з’являється коротка дія «Закріпити розділ», якщо в ньому є вже пройдені тобою картки. Вправи використовують лише ці картки, а потім пропонують короткий переказ і запитання «чому?». Результати зберігаються локально.

## Оновлення через GitHub Desktop

1. Відкрий поточний English Pocket і зроби **⚙ → Зберегти все**. Збережи JSON на комп'ютер.
2. Завантаж `English_Pocket_23_0_GitHub_Pages.zip` і розпакуй його.
3. У GitHub Desktop вибери репозиторій `english-listening-pocket` (гілка `main`) → **Show in Explorer**.
4. Скопіюй **весь вміст** розпакованого ZIP поверх файлів у корені репозиторію. Не видаляй `.git` і не створюй вкладену папку `pocket23_build`.
5. Переконайся, що `index.html`, `pocket23.js`, `pocket23.css`, `sw.js` знаходяться поряд. На GitHub Desktop з'являться змінені й нові файли.
6. Summary: `English Pocket 23.0 dictionary, shadowing, chapter learning` → **Commit to main** → **Push origin**.
7. Відкрий `https://ujenpost-lgtm.github.io/english-listening-pocket/`. Якщо PWA показує стару версію, закрий і відкрий її заново. Не очищай дані сайту.

## Як встановити великий офлайн-словник

1. Відкрий офіційну сторінку [koreader-dicts — Downloads](https://danielgregorini.github.io/koreader-dicts/en/downloads/).
2. Знайди **English → Ukrainian (en-uk)** і натисни Download; завантаж оригінальний `en-uk.zip` (близько 2,6 МБ). **Не розпаковуй** його.
3. В English Pocket відкрий ⚙ → **Великий словник офлайн** → **Імпортувати ZIP** і вибери завантажений файл.
4. Дочекайся статусу «Встановлено ... статей / ... словоформ». Можна відключити інтернет — імпортований словник продовжить працювати локально.
5. Відкрий книгу й натисни **walking**, **bought**, **bank**: мають знаходитися словоформи або значення з локального словника, якщо вони є в оригінальному пакеті.

**Ліцензія й джерело:** словник `en-uk` від [DanielGregorini/koreader-dicts](https://github.com/DanielGregorini/koreader-dicts), утворений із відкритих джерел, розповсюджується за **CC BY-SA 4.0**. Оригінальний словник містить ліцензію та атрибуції. Додаткові відомості в `DICTIONARY_ATTRIBUTION.md`.

**Важливо:** повний словник зберігається у *власному локальному сховищі браузера* і **не входить у JSON-резервну копію** English Pocket (він великий, а першоджерело доступне для повторного імпорту). При переїзді на новий телефон імпортуй `en-uk.zip` повторно. Картки, прогрес SRS і книги зберігаються в попередніх сховищах і не змінюються цим оновленням.

## Обмеження

- Великий словник дає переклади **слів і словоформ**, а не гарантовано точний переклад будь-якого речення. Не всі значення або колокації будуть охоплені; потрібно вибирати значення з урахуванням контексту.
- Shadowing використовує встановлений на пристрої голос Web Speech API. Чоловічий голос можливий, тільки якщо він є серед системних голосів. Запис / автоматичне оцінювання вимови не додаються.
- «Слова з розділу» — це **підказки** на основі частотності в розділі й локального словника; це не сертифікована CEFR-класифікація складності.
- Створені для тесту штучні словникові дані **не включені** у фінальний ZIP. Тест на фізичному Android/iPhone, а також імпорт справжнього словника з офіційного сайту ще потрібно виконати після встановлення.

## Перевірено

- Синтаксис усіх JS-модулів.
- Ізольований Chromium: імпорт тестового StarDict ZIP, 25 505 статей і 80 004 словоформи, вибір кількох значень, відбір слів реального тестового розділу, збереження картки, закріплення тільки вивчених фраз та відкриття shadowing без JS-помилок.
- Цілісність архіву ZIP і наявність нових файлів у кеші PWA.

Повне тестування на телефоні та з реальним зовнішнім словником ще не проведено; в разі проблем із його конкретним форматом потрібне додаткове коригування імпортера.
