# English Pocket 21.0 — встановлення та використання

## Оновлення GitHub Pages

1. У поточному застосунку відкрий **⚙ → Зберегти все**. Перевір, що файл повної копії зберігся, і збережи його поза браузером.
2. Завантаж `English_Pocket_21_0_GitHub_Pages.zip`, розпакуй. Усередині **в корені** лежать `index.html`, `app.js`, інші JavaScript/CSS, `manifest.webmanifest`, `sw.js` та іконки.
3. Перейди до репозиторію: https://github.com/ujenpost-lgtm/english-listening-pocket
4. Замінюй **усі** наявні файли сайту файлами нової версії, не лише `index.html`. Зверни увагу на нові `pocket21.js` та `pocket21.css` і змінений `sw.js`.
5. Натисни **Commit changes**, дочекайся публікації GitHub Pages та відкрий: https://ujenpost-lgtm.github.io/english-listening-pocket/
6. Якщо стара версія залишилася в PWA, закрий застосунок повністю, відкрий сайт у браузері онлайн і перезапусти встановлений застосунок. **Не очищай дані сайту** — там твій словник і книги.

Оновлення не відправлялося на GitHub автоматично. Локальний браузер зберігає книги у IndexedDB, слова й прогрес — у localStorage; змінювати адресу сайту не потрібно.

## Де нові функції

**Слова → Навчання → 🎯 Закріплення** (згорнутий блок під навчанням):

- **Складні:** три вправи зі слабкою вивченою карткою, озвучування та приклади з твого словника.
- **Схожі:** вибір між двома вже вивченими виразами.
- **Історії:** короткий оригінальний текст, озвучування, питання на розуміння і за наявності контекстне завдання.
- **Тиждень:** до шести карток зі щотижневим підсумком.
- Нижче в цьому ж блоці — **«Граматика з моїх помилок»**. Якщо конкретних розпізнаних помилок немає, секція буде порожньою.

**Слова → Мої картки → Перевірити якість карток**: недоліки, редагування, за підтвердженням — об'єднання точних дублікатів. У редакторі картки є згорнуте поле **«Інші правильні варіанти»** — по одному в рядку.

**Читати → відкрита книга → ☰ → Aa Текст → Закріпити розділ**: повторення збережених із розділу вивчених фраз. Старі картки без координат розділу не відбиратимуться автоматично.

**Слова → Діалоги з життя в Канаді → Ситуація змінилася**: вибір двох варіантів для кожної з п'яти тем, логічні репліки, озвучування, перевірка вживання вже вивчених цільових фраз. Неофіційні демонстраційні розмови — не консультації щодо оренди, медицини або банку.

## Поради для A2+ → B1

Звичайна сесія: спочатку прострочені SRS-картки; потім 3–5 нових; якщо є час — 3–6 хвилин цільової практики. Не потрібно відкривати все щодня. Додаткові режими не замінюють основний навчальний цикл.

## Особливості та обмеження

- Без AI: автоматичної перевірки всього відкритого речення немає; користуйся зразком і самоперевіркою.
- «Майже правильно» для одиничної друкарської помилки не зараховує фразу як засвоєну, а просить виправити написання.
- Історії — **попередньо написані**, а не згенеровані з випадкових фраз. Тренуються лише їхні цільові вирази, які вже вивчені.
- Для озвучування потрібні доступні англійські голоси пристрою. Для офлайн-озвучування відповідні голоси мають бути встановлені на пристрої.
- Безплатний онлайн-переклад, як і в попередній версії, може вимагати інтернету та інколи бути недоступним.
- Стан тижневого заняття входить у нову повну резервну копію. Існуючий формат карток збережений.

## Що перевірити після встановлення

1. Відкрити свою книгу, перегорнути свайпом та озвучити вибране речення.
2. Вивчити одну нову картку і перевірити, що вона з'являється у звичайній практиці лише після завершення уроку.
3. Відкрити «🎯 Закріплення»: невивчені картки не повинні з'являтися.
4. Перевірити збереження між закриттями браузера і можливість зробити повну резервну копію.
5. У канадському діалозі спробувати лише вивчені репліки.

### Якщо побачиш збій

Зроби скриншот екрана, запиши фразу, очікуваний результат, фактичний результат і назву браузера/моделі телефона. **Не очищай сховище**, доки не збережеш резервну копію.
