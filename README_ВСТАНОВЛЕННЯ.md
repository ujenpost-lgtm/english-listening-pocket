# English Pocket 20.3 — оновлення та користування

## Перед оновленням

**Обов'язково збережи резервну копію:** відкрий встановлений English Pocket → ⚙ → **«Зберегти все»**. Переконайся, що JSON завантажився, і не видаляй старі дані браузера.

## Оновлення GitHub Pages

1. Завантаж `English_Pocket_20_3_GitHub_Pages.zip` і розпакуй.
2. Відкрий свій репозиторій: https://github.com/ujenpost-lgtm/english-listening-pocket
3. У папці публікації GitHub Pages заміни старі файли вмістом архіву, включно з `index.html`, `app.js`, усіма `learning*.js`, `pocket20*.js`, `pocket20*.css`, `sw.js`, іконками та маніфестом. **Не завантажуй ZIP замість файлів.**
4. Натисни **Commit changes**, перевір завершення розгортання у GitHub Actions / Pages.
5. Відкрий https://ujenpost-lgtm.github.io/english-listening-pocket/ , закрий і повторно відкрий PWA на телефоні, за потреби перезавантаж сторінку. У нижній частині має бути **English Pocket 20.3**.
6. Перевір кілька своїх карток, у яких раніше були помилки. Прогрес 20.2 має залишитися; розподіл за навичками почне накопичуватися від відповідей у 20.3.

## Де шукати нове

- **Слова → Навчання → Додаткова практика**: контекст / диктант / вимова. Складні фрази мають пріоритет; картки, яких ти ще не пройшов, не потрапляють у ці вправи.
- Якщо в картці є декілька власних прикладів із цією фразою, контекстні пропуски поступово чергуються.
- Під **«Додаткова практика»** з'являється мінімалістичний підсумок після першої відповіді за день.
- **Слова → Діалоги для життя в Канаді**: після вибору теми побачиш **«Складні репліки»**, якщо серед вивчених фраз сценарію є ті, над якими потрібно попрацювати. Якщо таких немає, кнопка не показується.
- **Мої картки → Складні ↻**: загальний список проблемних фраз із попередньої версії залишається.

## Що важливо

- У попередній історії 20.2 немає надійного поділу на три навички. Вона не зникає, але точні навичкові сигнали накопичуються під час наступних відповідей у 20.3.
- Для зняття статусу складної фрази потрібні правильні пригадування в різні дні. Однієї вдалої спроби недостатньо.
- Контекстні вправи не вигадують нових речень. Якщо в картці немає прикладу, додай його через «Мої картки».
- Вільні англійські відповіді в канадських діалогах оцінюються за наявністю потрібної цільової фрази, **не** за граматичною повнотою або семантичною еквівалентністю всього речення.
- Короткий підсумок дня зберігається на поточному пристрої; основні показники навичок записуються всередині карток і потрапляють у повну JSON-копію. Очищення даних браузера може їх стерти — роби копії регулярно.
- EPUB, онлайн-переклад і голосові можливості залишилися без змін. Для окремих функцій, як і раніше, потрібен інтернет або підтримка браузера.

## Рекомендована перевірка на телефоні

1. У «Мої картки» переконайся, що словник на місці.
2. Відкрий «Додаткова практика → Контекст», помилися на одній фразі й пройди наступне завдання.
3. Перейди на «🎧 Диктант»: перевір озвучування, правильність відповіді та стабільність порядку карток.
4. Повернися до попередньої фрази або перезапусти PWA — історія труднощів має зберігатися.
5. Відкрий канадський сценарій із уже вивченими проблемними репліками. Пройди точкове повторення.
6. Експортуй повну копію ще раз після кількох вправ.

Оновлення не публікувалося автоматично на GitHub. Файли у ZIP — готовий пакет для завантаження.
