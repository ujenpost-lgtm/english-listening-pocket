# English Pocket 24.3.0

Оновлення 24.2.0. Три вкладки залишилися: Читати, Слова, Відео. Підписка Busuu не потрібна для функцій застосунку; канали Боба, Vanessa та інші збережено. Історії — один активний текст, без автоматичної ротації.

## Відеотренажер

У «Відео» відкрий «Відеотренажер · моє відео». Можна вставити HTTPS-посилання на конкретний ролик YouTube або відкрити ролик із каталогу / поточного модуля курсу. «Дивитися тут» завантажує офіційний YouTube IFrame Player API; натисни Play. Ролики, які власник заборонив вбудовувати, відкривай через YouTube ↗. Плеєр потребує інтернету і підключення до YouTube, тому не працює повністю офлайн.

1. У блоці «Фрагмент» встанови початок і кінець (хв:сек), увімкни повтор. Можна зняти час із плеєра. Субтитри та швидкість контролюються стандартним плеєром YouTube. Два проходи позначаються вручну; це не доказ розуміння.
2. У «Збережи почуту фразу» натисни «Поточний момент», введи фразу, українське значення і за бажанням речення. Картка додається до наявного словника, а джерело — до відеоблокнота. Дублікати не створюються.
3. У «Підсумок і практика» збережи основну думку й дві деталі. Для відео поточного модуля ці нотатки можна перенести до Watch. Завершення Watch підтверджується окремо у курсі.
4. «Слуховий тест» бере лише вже вивчені картки з цього конкретного ролика; використовує системний голос, не звукову доріжку YouTube. Нові слова проходять наявний цикл навчання.

Позиція зберігається під час перегляду й при закритті плеєра. При переході в інший розділ відтворення припиняється. Вбудована інтеграція не завантажує субтитри й не оцінює автоматично вимову.

## Слова

Місія дня: коротка (до 3 карток) або розширена (до 6). Є лічильники прострочених, складних, нових і вивчених карток. Прострочені повторюй за SRS, а місія тренує активні навички. Вибір залежить від слабкої навички та дати повторення; після добірки щойно показані картки тимчасово отримують менший пріоритет. Помилки повертаються наприкінці, підказки не зараховуються як незалежна правильна відповідь. Незавершені сесії можна продовжити наступного дня. Вже встановлені ключі SRS і карток не скидаються.

## Читалка

- Торкнися слова або виділи фразу/речення. Пошук використовує власні картки, імпортований StarDict, базові словники, скорочення та словоформи. Підтримує довші виділення до 800 символів; картки — до 300. Для багатозначних слів вибери потрібне значення. «Усе речення» показує контекст, якщо він доступний.
- Якщо точного перекладу немає, відкрий «Словникові підказки»: це значення окремих слів і виразів, не повний переклад. Для великого словника: ⚙ → Великий словник офлайн → імпортуй en-uk.zip із https://danielgregorini.github.io/koreader-dicts/en/downloads/ (зберігається на кожному пристрої окремо).
- «Модель на пристрої» доступна лише за наявності браузерного Translator API; для першого запуску може знадобитися завантаження моделі. Якщо готова модель є, невідомий фрагмент може перекладатися автоматично локально. Chrome підтримує Translator на комп'ютерах, не на мобільних пристроях (https://developer.chrome.com/docs/ai/translator-api).
- «Перекласти онлайн» — додаткова явна дія: тільки після підтвердження відправляє виділений текст MyMemory. Не надсилай приватних текстів. Безкоштовний сервіс має обмеження, може бути недоступний або неточний; перевір результат. Отриманий результат кешується локально (до 400 останніх записів; старі витісняються). Наступне відкриття того самого невідомого фрагмента працює офлайн. Якщо сервіс недоступний, можна відкрити зовнішній Google Translate або написати переклад вручну. Немає автоматичного надсилання тексту до MyMemory.
- Гортання: свайп, стрілки або кнопки внизу. Новий 3D-аркуш із тінню, зворотним боком та імітацією паперу; не фізична симуляція згину. На дуже довгому розділі анімація вимикається задля продуктивності. Налаштування «Гортання з ефектом книги» та системне reduced motion враховуються.

## Оновлення

1. У поточному English Pocket: ⚙ → «Зберегти все». Збережи також окремий ZIP великого словника, бо він зберігається в окремій IndexedDB.
2. Розпакуй релізний ZIP. GitHub Desktop → Repository → Show in Explorer. Скопіюй файли з архіву поверх старих, не видаляй .git.
3. Commit to main: `Update English Pocket to 24.3.0`; Push origin.
4. Після публікації GitHub Pages перевір https://ujenpost-lgtm.github.io/english-listening-pocket/version.txt — English Pocket 24.3.0. Запуск: https://ujenpost-lgtm.github.io/english-listening-pocket/ . Якщо потрібне оновлення, закрий вкладки/PWA та відкрий повторно. Не очищуй дані сайту без резервної копії.

## Перевірка

Синтаксис усіх JS, перевірка ZIP, запуск Chromium із мобільним viewport та імітованим localStorage: фінальний підпис 24.3.0, відбір вивчених карток, ротація між добірками, локальні словоформи й підказки, запис нової фрази з відео (не включено до тесту), пагінація тестової книги та анімація. Імітований YouTube Player: позиція, повтор фрагмента, два проходи; імітована відповідь MyMemory: кеш і повторне локальне отримання. Мережеві виклики, реальний YouTube, реальна модель Chrome, фізичний телефон, довготривала IndexedDB та публікація GitHub Pages не перевірені в цьому середовищі. Повноцінний офлайн-переклад довільних речень на телефоні не гарантовано.
