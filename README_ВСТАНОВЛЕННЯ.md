# English Pocket 15.0 — встановлення та користування

## Що змінилося

**Слова**: один простий маршрут — **Вивчаю → Практикую → Перевіряю**. Щоденна добірка з 3, 5, 7 або 10 нових карток (типово 5). На всіх трьох етапах використовуються саме ті самі фрази. Після перевірки вони переходять до SRS; неправильні відповіді повторюються раніше. Незавершена добірка зберігається. Окремо можна повторити вже вивчені картки. Озвучування є у картках, словнику та SRS.

**Читати**: у разі відкриття книги вона завжди займає весь екран застосунку (без постійного меню навігації). Свайп ліворуч/праворуч або кнопки ◀/▶ перегортають сторінку. Верхній рядок — повернення до бібліотеки, назва книги, прогрес, озвучити та меню ☰. У меню — розділи, шрифт, тема, пошук і закладки. Тап по слову або виділення фрази/речення відкриває компактну нижню панель, а не велике модальне вікно.

## Як працює переклад без AI API

- **Відомі слова/фрази**: український переклад береться локально з твого словника або підготовлених навчальних карток (точний збіг).
- **Нові слова, фрази та речення**: натисни **«🌐 Перекласти»**. Застосунок відкриє Google Translate з переданим саме виділеним текстом. Скопіюй український переклад і встав у поле невеликої панелі. Натисни **«＋ У словник»** — фраза, переклад і речення-контекст збережуться разом.
- Це **не автоматичний переклад усередині програми**: довільний текст без перекладацької моделі або зовнішнього сервісу перекласти локально неможливо. Офіційний сайт Google Translate відкривається **тільки після явного натискання**; для цього потрібна мережа. Жодних платних API, прихованих запитів чи ключів немає.

## Озвучування

Кнопка **🔊** використовує стандартний браузерний `SpeechSynthesis` з англійською мовою, де вона підтримується. Кнопка у верхній панелі читалки озвучує видимий текст (довгі абзаци можуть відтворюватися частково). Кнопка у панелі перекладу — виділене слово, фразу чи речення; кнопка у картці — англійський вираз. Не всі пристрої мають встановлені голоси англійської для роботи офлайн; якість залежить від браузера й ОС.

## Як оновити GitHub Pages

1. **Спершу збережи повну резервну копію** у старому English Pocket: ⚙ → «Зберегти все» (JSON), збережи її поза браузером. Також за потреби збережи початковий ZIP із поточною версією як можливість відкату.
2. Завантаж архів `English_Pocket_15_0_GitHub_Pages.zip` і **розпакуй** його.
3. Увійди до репозиторію https://github.com/ujenpost-lgtm/english-listening-pocket на GitHub. Перевір у Settings → Pages, з якої гілки й каталогу розгортається сайт.
4. Замінюй файли в **корені публікованої папки** файлами з ZIP (зокрема `index.html`, `app.js`, `learning_reader15.js`, `sw.js` та іншими ресурсами). Не завантажуй ZIP як один файл замість розпакованих ресурсів.
5. Зроби **Commit changes**. Відкрий https://ujenpost-lgtm.github.io/english-listening-pocket/ і перевір, що з’явилася версія **15.0**. За потреби повністю закрий/відкрий встановлену PWA; кеш service worker має нове ім'я.
6. Дані із попереднього застосунку повинні залишитися у браузерному сховищі **тієї самої адреси**. Не очищай дані сайту. Якщо даних немає — скористайся ⚙ → «Обрати JSON» та імпортуй резервну копію.

## Три перевірки після оновлення

- **Читалка:** відкрий EPUB; проведи пальцем ліворуч; виділи фразу; переконайся, що з'явилася компактна нижня панель; натисни 🔊.
- **Картки:** відкрий «Слова» → «Навчання»; вибери 5; пройди знайомство, вправу, тест; перевір, що нові фрази перейшли до повторення.
- **Резервна копія:** ⚙ → «Зберегти все»; переконайся, що JSON завантажився. Експорт містить слова, SRS, поточну навчальну сесію, книги та закладки.

## Важливі обмеження

Зміни перевірені в автоматизованому Chromium на мобільній ширині екрана. Повноцінне тестування озвучування та системного виділення тексту на фізичному Android/iPhone ще потрібне. Синтез мовлення і робота довгого натискання залежать від браузера. EPUB із DRM, деякими нетиповими макетами або дуже великими медіафайлами можуть потребувати окремих поліпшень.

Застосунок зберігає дані локально (IndexedDB для книг, localStorage для карток і SRS). **Оновлення без зміни адреси** має зберегти дані, але резервна копія перед встановленням обов'язкова. Не видаляй попередні дані сайту.
