# English Pocket 24.3.1 — Reader UX Fix

## Що виправлено

- Прибрано конфлікт між браузерним виділенням тексту та старими обробниками читалки.
- Слова перекладаються одним натисканням; речення — кнопкою «Речення»; фраза вибирається двома натисканнями (перше та останнє слово).
- Підсвічування створюється окремим візуальним шаром, а не системним виділенням. Це прибирає необхідність нативного контекстного меню в тексті книги.
- Одне компактне меню перекладу: «Слово / Фраза / Речення / Копіювати», озвучування, офлайн-переклад, за згодою онлайн-переклад, збереження до особистого словника.
- Кнопка «Речення» у старому меню прихована, щоб не було дублювання.
- Підказку під час вибору фрази перенесено над сторінкою: вона не перекриває рядки книги.
- Збережено свайпи/перегортання, великий офлайн-словник, відеомодулі, картки та SRS.
- Узгоджено підпис і PWA-кеш із 24.3.1. Наявні локальні дані не очищуються.

## Як користуватися

1. Відкрий книгу й **натисни на слово**. Відкриється переклад.
2. Хочеш **ціле речення** — натисни «Речення».
3. Хочеш **фразу** — натисни «Фраза», а потім **торкнися останнього слова** потрібної фрази у тому самому абзаці. Можна вибрати слово перед початковим: межі будуть упорядковані автоматично.
4. У панелі перекладу доступні «Озвучити», «Перекласти онлайн» за твоєю згодою, текст українською для редагування, «У словник» і «Копіювати».
5. Якщо передумав під час вибору фрази, натисни «Скасувати» або клавішу Esc.
6. Під час перегортання виділення закривається автоматично.

**Важливо:** ми свідомо вимкнули системне виділення тексту *тільки в самій сторінці книги*, щоб не з’являлися два меню. Для копіювання обраної фрази є кнопка «Копіювати». У текстових полях і решті застосунку системне виділення працює як раніше.

**Межі:** фраза вибирається в межах одного абзацу (до 800 символів), слово або речення — за натисканням. Для збереження картки діє попереднє обмеження 300 символів. Деякі системні контекстні меню залежать від браузера/ОС — перевір на своєму телефоні. Довільні речення без локальної моделі чи кешу можуть потребувати онлайн-перекладу лише після явної згоди.

## Перевірки

- Chromium, мобільний 390×850: натискання слова, речення, дві точки фрази, відсутність нативного виділення, закриття панелі — **пройдено**.
- Chromium, десктоп 1100×850: аналогічний сценарій, без перекриття тексту підказкою — **пройдено**.
- Chromium, rich-text EPUB з `<strong>`/`<em>`: слово, речення, фраза, збереження картки, зміна сторінки 1→2, очищення підсвічування — **пройдено**.
- Синтаксис JavaScript, комплектність ZIP та `version.txt` — **перевірено**.
- Фізичний Android/iOS, голос, великий реальний StarDict і зовнішні онлайн-сервіси — **не перевірено**.

## Оновлення через GitHub Desktop

1. У старому English Pocket зроби резервну копію через ⚙ → «Зберегти все».
2. Розпакуй ZIP і скопіюй *файли всередині* до папки репозиторію (Repository → Show in Explorer), із заміною.
3. Перевір, що `index.html`, `pocket244.js`, `pocket244.css` і `sw.js` лежать у корені репозиторію.
4. У GitHub Desktop виконай Commit to main → Push origin.
5. Перевір `https://ujenpost-lgtm.github.io/english-listening-pocket/version.txt` (має бути `English Pocket 24.3.1`).
6. Відкрий застосунок. Не очищай дані браузера, щоб не втратити локальні книги, картки та прогрес.
