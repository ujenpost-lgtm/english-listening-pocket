# English Pocket 14.0 — інструкція

**Основна адреса застосунку:** https://ujenpost-lgtm.github.io/english-listening-pocket/

English Pocket 14.0 — три розділи: Читати, Слова, Відео. Немає AI API або сервісів автоматичного перекладу. Книги, картки та прогрес локальні. Відеоуроки відкриваються на офіційних сайтах і потребують інтернету.

## 1. Перед оновленням — обов'язково

1. Відкрий попередню версію English Pocket **на тому самому пристрої, де зберігаються дані**.
2. Експортуй **повну резервну копію** (книги, словник, прогрес) та збережи JSON **поза браузером**: «Файли», Google Drive тощо.
3. Переконайся, що JSON реально завантажився. **Не очищай дані сайту, не видаляй стару PWA до перевірки нової версії**.
4. Старі книги з IndexedDB та словник з localStorage залишаються на тому самому сайті/у тому самому браузері після заміни файлів. Але новий пристрій, інший браузер та встановлена PWA на iOS іноді використовують інше сховище — тоді потрібно імпортувати резервну копію.

## 2. Оновити GitHub Pages

1. Скачай `English_Pocket_14_0_GitHub_Pages.zip` та **розпакуй**.
2. У GitHub відкрий репозиторій `ujenpost-lgtm/english-listening-pocket` (або інший репозиторій, який реально живить сайт). У `Settings → Pages` перевір активну гілку та папку публікації.
3. Завантаж **окремі розпаковані файли** в папку публікації, зокрема `index.html`, `app.js`, `starter_cards.js`, `pako.min.js`, `manifest.webmanifest`, `sw.js`, іконки й ліцензію. Важливо: `index.html` і `app.js` мають лежати поруч; не створюй випадково додаткову вкладену папку.
4. Зроби `Commit changes`.
5. Відкрий https://ujenpost-lgtm.github.io/english-listening-pocket/ та онови сторінку. У встановленій PWA закрий і відкрий її. Service worker має оновлений кеш версії `english-pocket-14-20261022`.
6. Перевір, що у футері написано **English Pocket 14.0**.

Якщо GitHub Pages використовує GitHub Actions, а не публікацію з гілки, файли потрібно оновити в тому шляху, який використовує workflow.

## 3. Установити на телефон

**Android (Chrome):** відкрий опубліковану HTTPS-адресу → меню ⋮ → «Встановити застосунок» або «Додати на головний екран». Назва пункту залежить від версії браузера.

**iPhone (Safari):** відкрий адресу → «Поділитися» → «На початковий екран» → «Додати».

Не намагайся встановити PWA безпосередньо з ZIP або локального HTML: для service worker потрібен HTTPS (виняток — localhost для розробників).

## 4. Як працювати

### 📖 Читати

- `Додати книгу` → обери EPUB (без DRM), TXT або HTML. Стиснені EPUB відкриваються за допомогою включеної локальної бібліотеки `pako.min.js`.
- Перегортай **свайпом вліво/вправо** або кнопками `Назад` / `Далі` (на комп'ютері — також стрілками на клавіатурі).
- `⚙ Текст` → шрифт, міжрядковий інтервал, поля, тема та спрощений режим читання.
- `⌕` → пошук слова по всій книзі; `☆` → закладка, список закладок — у `⚙ Текст`.
- Торкнися слова або виділи фразу → відкриється картка з контекстом. Введи значення українською та збережи. Уже збережені вирази підкреслюються в тексті.
- `Фрази` біля книги → побачиш картки саме з неї. `Продовжити читання` → останнє місце.

### 🧠 Слова

- **Мої картки** — усі слова в одному місці, пошук, фільтри, редагування, примітки, обране.
- **Повторити** — SRS з адаптивними інтервалами: `Знову`, `Важко`, `Добре`, `Легко`. У налаштуваннях вкладки — ліміт 3/5/7/10 нових на день і напрям запитання. Повторення з датою на сьогодні йдуть першими.
- **Практика** — переклад фрази, пропуски або власне речення. **Власні речення оцінюєш самостійно** за зразком; застосунок не удає граматичний аналізатор.
- Нові картки без перекладу видно у списку, але вони **не включаються в SRS**, доки не додаси значення.
- До 80 стартових карток: `⚙ → Додати мої 80 фраз` (дублікати пропускаються).

### ▶ Відео

- Обери тему, рівень B1/B2 або шукай назву уроку.
- `Відкрити` переводить на сторінку відповідного постачальника навчального матеріалу; зовнішнє відео потребує інтернету.
- `Переглянув` — фіксує прогрес, `＋ Фраза` — збереження вислову з уроку у свій словник.
- Після перегляду корисно коротко переказати відео і зберегти 1–2 конструкції.

## 5. Резервна копія та імпорт

- ⚙ → **Зберегти все**: один JSON із книгами (включно з обкладинками/ілюстраціями), позиціями, закладками, словником, історією SRS, локальними налаштуваннями та переглянутими відео.
- ⚙ → **Обрати JSON**: імпорт резервних копій English Pocket 11–14 або файлів карток із `en`, `uk`, `context` чи `text`, `meaning`, `example`. Перед імпортом перевіряються структури карток і книг. **Існуючі книги не перезаписуються**, картки об'єднуються за нормалізованим англійським текстом.
- Резервна копія може бути великою, якщо в книгах багато зображень. Зберігай копію в надійному місці.

## 6. Обмеження й сумісність

- Файли захищених DRM книг не підтримуються. Важке форматування EPUB, зовнішні шрифти, відео/аудіо всередині EPUB можуть не зберегтися; основні заголовки, акценти та вбудовані raster-ілюстрації зберігаються, коли формат їх дозволяє.
- Це статичний застосунок без сервера та платного AI. Переклад нової незнайомої фрази вводиться вручну. Немає автоматичної граматичної перевірки власних речень.
- Дані живуть у браузерному localStorage та IndexedDB. Повне очищення даних сайту видалить їх. Якщо браузер працює в приватному режимі або очищає сховище, обов'язково роби резервні копії.
- Відкриті зовнішні відео потребують мережі; бібліотека та вправи після першого завантаження вебзастосунку можуть працювати офлайн, поки браузер зберігає кеш.

## 7. Що перевірено

Автоматизовані локальні сценарії у headless Chromium (із браузерним тестовим сховищем):

- імпорт тестового стисненого EPUB з обкладинкою, XHTML-заголовками й ілюстрацією;
- перегортання **синтетичним touch-свайпом** `1/82 → 2/82`;
- відновлення збереженої сторінки, пошук, закладки;
- виділення фрази та додавання картки з перекладом, контекстом, приміткою й обраним;
- 80 стартових карток, SRS, вправа на власне речення;
- фільтрація відеоуроків за рівнем;
- повний JSON-експорт та імпорт у чисту тестову копію.

У перевірених сценаріях JavaScript-помилок не було. **Фізичні Android/iPhone і реальний GitHub Pages після публікації ще не перевірені.**
