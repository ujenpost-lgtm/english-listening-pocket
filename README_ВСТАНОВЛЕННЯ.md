# English Pocket 22.0 — встановлення та використання

**Мета:** A2+ → B1. Три головні розділи: Читати · Слова · Відео. Платного AI API немає.

## Як безпечно оновити GitHub Pages

1. **Зроби резервну копію.** Відкрий попередню версію English Pocket за звичною адресою → ⚙ → «Зберегти все». Збережи отриманий JSON у надійному місці. Важливо: експорт має завершитися перед оновленням.
2. Завантаж архів `English_Pocket_22_0_GitHub_Pages.zip` і розпакуй його. Усередині `index.html`, JS/CSS, словник `offline_lexicon22.js`, `sw.js`, іконки та інші файли.
3. Відкрий репозиторій `https://github.com/ujenpost-lgtm/english-listening-pocket` та в його папці публікації завантаж **увесь вміст** розпакованого пакета (не ZIP як один файл). Заміни одноіменні файли. Зроби Commit changes.
4. Перевір після розгортання: `https://ujenpost-lgtm.github.io/english-listening-pocket/`. Якщо відображається стара версія, закрий установлену PWA, відкрий сайт знову і зроби перезавантаження. За потреби зачекай завершення розгортання GitHub Pages. Не очищай дані сайту без резервної копії!
5. Перевір на телефоні: відкриття EPUB → свайп → виділення фрази → локальне значення → озвучити → зберегти в словник; потім «Слова» і «Відео».

## Зміни у версії 22.0

### Читати
- Оновлений синьо-сапфіровий інтерфейс, темний / світлий режим.
- Гортання сторінок з короткою 3D-анімацією; анімація вимикається у ⚙. Системне налаштування «Зменшення руху» теж поважається.
- Текст можна виділяти штатним жестом. Компактна нижня панель пропонує локальне значення, озвучування й збереження картки з контекстом. Наявне виділення тексту та свайпи не замінено стороннім модулем.
- **Локальний словник:** 368 вручну укладених поширених слів/виразів плюс усі наявні власні картки та попередні навчальні словники. Для слова/фрази спочатку показується точне значення. Для цілого невідомого речення показуються лише впізнані складові з явним попередженням, а не вигаданий «повний переклад».
- **Повний переклад речення офлайн** можливий лише в браузерах, де доступний системний `Translator` і відповідна мовна модель. На більшості мобільних браузерів ця можливість наразі відсутня. Мовна модель браузера може потребувати окремого завантаження; застосунок не робить цього без окремої дії.
- Озвучування з вибором установленого англійського голосу в ⚙, тестом голосу та швидкістю із наявних налаштувань. Якщо пристрій не має бажаного чоловічого голосу, його не можна гарантувати програмним кодом.
- Підсвітка поточного абзацу під час озвучування кнопкою сторінки або у режимі прослуховування абзаців. Точна синхронізація кожного слова не гарантується.
- Перелік збережених фраз поточної книги у меню читалки та короткий навчальний підсумок розділу із збереженням відповідей.

### Слова
- Вбудовано в **наявний** щоденний план, без дублювання екрана: вибір вправи з огляду на слабку навичку (пригадування / слух / використання).
- Історія відповідей і SRS лишаються на картках. Рівні навичок показуються у згорнутому блоці редактора картки; вони базуються на реально виконаних вправах, а не на AI-оцінці.
- Для деяких частих конструкцій додано підготовлені приклади в інших контекстах. Це тільки для **вже вивчених** фраз. Нові фрази, як і раніше, лише зі свого словника.
- Денний план пропонує менше нових фраз, коли накопичились повторення.

### Відео
- Стиснутий маршрут із 8 доступних матеріалів A2–B1, із пріоритетом простіших тем.
- Два проходи: без субтитрів → з англійськими субтитрами. Можна окремо відзначати їх завершення.
- Питання на зміст і короткий письмовий переказ зберігаються локально. Готові питання до конкретних матеріалів використовуються, якщо є.
- Можна вручну зберегти фразу, переклад і часову позначку відео; фраза потрапить у чергу нових карток, а не автоматично до вивчених.
- Відео залишаються на офіційних сайтах їхніх авторів.

## Важливі обмеження
- **Немає універсального якісного офлайн-перекладача довільних речень на Android/iPhone.** Локальний словник корисний для точних слів та знайомих виразів, але це не модель машинного перекладу. Краще порожній переклад, ніж помилковий.
- Якість і наявність чоловічого голосу залежать від системних голосів телефона.
- EPUB з DRM не підтримуються. Результат гортання та виділення тексту потрібно перевірити на фізичному телефоні.
- Книги зберігаються в IndexedDB; картки та навчальні налаштування — в локальному сховищі браузера. Не очищай дані сайту без експорту.
- Пакет не публікувався в GitHub автоматично.

## Перевірки релізу
Перевірено синтаксис усіх власних JS-модулів, цілісність ZIP, інтеграційний запуск ізольованого Chromium без помилок JavaScript, точний офлайн-переклад знайомої фрази, відсутність хибного повного перекладу нового речення, 24 сторінки тексту й перехід 1 → 2, відеомаршрут і збереження двох переглядів. Тест ізольованого браузера не зміг підтвердити реальний IndexedDB через обмеження тестового середовища. Повне тестування Android/iPhone ще потрібне.
