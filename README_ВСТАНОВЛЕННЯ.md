# English Pocket 25.0.0 — коротка інструкція

## Оновлення через GitHub Desktop

1. У старій версії натисни **⚙ → Зберегти все** (повна JSON-копія книг, карток і навчального прогресу).
2. Розпакуй `English_Pocket_25_0_GitHub_Pages.zip` на комп'ютері.
3. Відкрий **GitHub Desktop → Repository → Show in Explorer**.
4. Скопіюй **усі файли всередині розпакованої папки** до кореня репозиторію; підтвердь заміну. Не видаляй приховану папку `.git`.
5. В GitHub Desktop введи Summary `English Pocket 25.0.0 — Personal Fluency Loop`, натисни **Commit to main** → **Push origin**.
6. Перевір [version.txt](https://ujenpost-lgtm.github.io/english-listening-pocket/version.txt): **English Pocket 25.0.0**. Відкрий [English Pocket](https://ujenpost-lgtm.github.io/english-listening-pocket/).

## Де шукати нові можливості

- **Слова → Навчання → Додаткова практика**: «Шлях однієї фрази», «Мій прогрес», «Speaking Studio».
- **Слова → Історії**: «Поглиблена робота з цією історією» (без автоматичної ротації).
- **Відео**: «Відео → Слова → Мовлення» — збережені відеофрази, практика та запис відповіді.
- **Читати**: тап на слово, потім «Фраза»/«Речення», джерело перекладу й пропозиція відомого сталого виразу.
- **⚙**: «Перевірка застосунку».

## Важливо для приватності

Аудіо Speaking Studio записується **тільки після дозволу на мікрофон** і зберігається окремо локально. Воно **НЕ входить до JSON резервної копії**: перед зміною телефона, очищенням даних сайту або перевстановленням завантаж записи окремо. Опціональна браузерна диктовка може обробляти звук на сервері браузера — запускається лише після окремого підтвердження.

Повний переклад довільних речень офлайн не гарантований на мобільних пристроях. Онлайн-переклад залишається лише за явною згодою. Навчальні досягнення — внутрішні показники, не сертифікація CEFR.
