# English Pocket 26.0.0 — оновлення та нові функції

## 1. Перед оновленням

1. У поточному English Pocket відкрий **⚙ → Зберегти все** та завантаж резервну копію JSON.
2. Якщо маєш голосові записи Speaking Studio — **завантаж їх окремо**, оскільки старий JSON 25.1.1 не включає аудіофайлів. Запам'ятай, які книги та слова були до оновлення.
3. Не видаляй застосунок, не очищуй браузерні дані та не змінюй адресу сайту.

## 2. Через GitHub Desktop

1. Завантаж `English_Pocket_26_0_GitHub_Pages.zip` та **розпакуй**.
2. У GitHub Desktop відкрий репозиторій `english-listening-pocket` на гілці `main`.
3. Натисни **Repository → Show in Explorer**.
4. Копіюй **вміст** розпакованої папки (разом із `pocket26.js` і `pocket26.css`) поверх старих файлів. Не видаляй `.git`.
5. У Summary введи `Update English Pocket to 26.0.0`, натисни **Commit to main → Push origin**.
6. Після публікації перевір https://ujenpost-lgtm.github.io/english-listening-pocket/version.txt — має бути `English Pocket 26.0.0`.
7. Відкрий https://ujenpost-lgtm.github.io/english-listening-pocket/ та перевір старі книги, картки й прогрес.

## 3. Де що знайти

- **⚙ → Data Vault:** «Повна копія: книги + голос + словник», імпорт архіву, локальні знімки, обережне відновлення. Для повного відкату потрібно окремо поставити галочку і підтвердити дію. Копії не завантажуються в хмару.
- **Слова → English Coach:** пропозиція найкориснішої вправи за помилками/термінами повторення.
- **Слова → Перевірка готовності до B1:** завдання з чотирьох навичок і ручна самооцінка.
- **Слова → Speaking Coach:** ситуації для живого спілкування; використовується вже наявний Speaking Studio для запису.
- **Слова → Історії:** випадаючий список семи текстів, «Наступна історія» й «Завершив → нова історія». Один текст відкритий за раз, **ротація ввімкнена**. Можна повернутися до раніше пройденої історії.
- **Читати:** натисни слово, обери слово/фразу/речення. У панелі перекладу натисни «✓ Запам'ятати переклад», якщо звірив його. У меню налаштування читання — «Читати без відволікань».
- **Відео → Video Detective:** конспект перегляду, повернення до часу збережених фраз, перевірка тільки вивченої лексики та speaking-переказ.

## 4. Два користувачі

На **різних пристроях** кожен має незалежні книги, слова та прогрес у локальному сховищі свого браузера. Ні хмарної синхронізації, ні перемикача профілів немає. Якщо перенести резервну копію між пристроями, роби це тільки свідомо.

## 5. Чесні технічні межі

- Універсальний переклад **довільних речень офлайн на кожному телефоні** не гарантовано; персональна пам'ять накопичує лише підтверджені переклади.
- Звіти B1 — самоперевірка, а не офіційний іспит.
- Повний JSON-архів може бути великим (до 140 МБ на експорт); **перевір файл після завантаження**.
- Автоматичні локальні знімки зникають після очищення даних браузера. Повний архів потрібно зберігати окремо.
- Відтворення YouTube, голос, справжній мікрофон і PWA на фізичному телефоні потрібно протестувати після встановлення.

Якщо щось не працює — спочатку надішли скриншот і не очищуй дані сайту.
