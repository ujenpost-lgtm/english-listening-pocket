# English Pocket 25.1.1 — Personal Device Edition

## Що змінилося

Перемикач профілів прибрано. Кожний пристрій і браузер використовує власне локальне сховище; між різними пристроями дані не синхронізуються. Інтерфейс зберігає три вкладки: Читати, Слова, Відео.

**Перехід із 25.0:** використовуються наявні `elp-*` ключі й попередні бази IndexedDB без копіювання.

**Перехід із 25.1:** залишається поточна активна область даних (`p1` або `p2`), яку було вибрано на останньому запуску 25.1. Жодна область не видаляється і не змішується. Книги, записи мовлення та імпортований офлайн-словник відкриватимуться з відповідної бази. Якщо на одному пристрої раніше використовували обидва профілі, дані неактивного профілю залишаються у сховищі, але не відображатимуться — для відновлення потрібно тимчасово повернути 25.1 та експортувати його резервну копію.

## Резервне копіювання

1. Перед оновленням у попередньому English Pocket відкрий ⚙ → Зберегти все. Завантажений JSON збережи в безпечному місці.
2. Після оновлення перевір, що книги, картки й результати видно.
3. Створи свіжу копію: ⚙ → Зберегти все. Починаючи з 25.1.1, копія отримує SHA-256 (у браузерах, де працює Web Crypto). При імпорті перевіряється контрольна сума.
4. Збережи файл поза браузером. Саме заміна коду на GitHub не повинна стирати локальне сховище, але видалення сайту, зміна браузера чи очищення даних можуть його стерти.
5. При відновленні натисни ⚙ → Обрати JSON. Імпорт не перезаписує наявні ключі навчання; щоб повернути **старі** результати поверх інших, потрібна окрема керована процедура, яку цей патч свідомо не виконує.

**Межі копії:** JSON містить книги, слова, позиції, SRS, історію помилок, відеопрогрес та налаштування. Він не містить бінарні голосові записи та великий імпортований словник StarDict. Їх слід експортувати / встановити окремо.

## Приймальний тест

- На пристрої 1 додай тестове слово й збережи копію.
- На пристрої 2 відкрий той самий URL: слова з пристрою 1 там не має бути.
- Переконайся, що в обох видно їхні окремі книги та результати.
- Перевір `version.txt`: `English Pocket 25.1.1`.

Гарантувати відновлення раніше втрачених даних без резервної копії неможливо.
