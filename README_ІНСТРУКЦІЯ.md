# English Pocket 13.0 — спрощена читалка, слова та відео

## Що змінилося

Замість складного English Pocket 11/12 є три розділи:

1. **Читати** — EPUB/TXT/HTML без DRM, бібліотека, збереження останньої сторінки, свайп ліворуч/праворуч, кнопки «Назад» / «Далі», зміна шрифту й теми. Натисни на слово, щоб відкрити картку; виділи фразу довгим натисканням, щоб зберегти її разом із контекстом.
2. **Слова** — «Мої картки» (де всі слова), «Повторити» (SRS: спочатку ті, що пора повторити, до п'яти нових на день), «Практика» (активне відтворення фраз / заповнення пропусків). Список карток із пошуком, редагуванням і поступовим показом по 20.
3. **Відео** — коротка добірка навчальних матеріалів British Council, VOA та BBC Learning English, позначка «Переглянуто», додавання фрази до словника. Якщо раніше був свій плейлист, він доступний внизу розділу під складеним блоком.

Кнопка ⚙ містить експорт повної резервної копії, імпорт старого JSON або нашого файлу фраз, та необов'язкове додавання 80 підготовлених фраз.

Платного AI, зовнішніх API для перекладу, зовнішніх скриптів, запису голосу та AI Coach немає. Пояснення/переклад додається вручну або береться з раніше збереженої картки. Для EPUB локально використовується бібліотека pako (MIT) — жодних запитів до її сервера.

## БЕЗПЕЧНИЙ ПЕРЕХІД зі старої версії

**Перед оновленням** відкрий поточний English Pocket за старою адресою. У вкладці «Книги» скористайся «Зберегти все» або іншим пунктом повного експорту з English Pocket 11/12. Збережи JSON-файл на пристрої. Не очищай дані сайту в браузері.

Нова версія використовує ті самі ключі `elp-words-v2` для словника та `english-pocket-library` для локальних книг. Якщо розмістити її за тією самою адресою і відкрити в тому самому браузері, попередні дані мають зберегтися. Старі необов'язкові налаштування залишаються в локальному сховищі й експортуються в резервну копію, навіть якщо їхній екран прибрано.

Якщо словник або книги не відображаються, **не видаляй стару копію**. Відкрий ⚙ → «Обрати JSON» і імпортуй попередній бекап. Імпорт слів об'єднує картки за текстом, уникаючи дублікатів.

## Як оновити GitHub Pages

1. Завантаж `English_Pocket_13_0_GitHub_Pages.zip` та **розпакуй ZIP**.
2. Відкрий GitHub-репозиторій, з якого публікується твій поточний сайт.
3. Переконайся, що GitHub Pages використовує гілку й папку, які ти редагуєш (Settings → Pages).
4. **Заміни** в папці публікації `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png` та додай `app.js`, `starter_cards.js`, `pako.min.js`, `PAKO-LICENSE.txt`. Усі файли мають лежати поруч із `index.html`.
5. Натисни **Commit changes** та дочекайся оновлення GitHub Pages (зазвичай кілька хвилин).
6. Відкрий **ту саму адресу** застосунку (зараз https://ujenpost-lgtm.github.io/english-listening-pocket/ ). Перезавантаж вкладку, за потреби закрий і відкрий PWA знову. Не натискай «Очистити дані сайту».
7. Перевір: імпорт/відкриття EPUB → свайп → картка слова → SRS → відео → ⚙ бекап.

**Не завантажуй ZIP безпосередньо як одну книжку на GitHub Pages**: сайт має бачити `index.html` і решту файлів **у розпакованому вигляді**.

## Встановлення на телефон

Після публікації за HTTPS:

- Android: відкрити сайт у Chrome → меню ⋮ → «Встановити застосунок» / «Додати на головний екран».
- iPhone: відкрити сайт у Safari → «Поділитися» → «На початковий екран» → «Додати».

Якщо застосунок уже був встановлений, зазвичай достатньо перезапустити його після оновлення сайту; не видаляй його до резервного копіювання даних.

## Використання

- **Картки** завжди у «Слова» → «Мої картки». Натискай «Повторити» для SRS; додавання 80 фраз — лише один раз і лише за бажанням у ⚙.
- Читалка працює офлайн після першого успішного завантаження PWA, якщо браузер зберіг файли; відео потребують інтернету.
- Переклади не надходять з мережі автоматично. Значення слів можна додавати вручну; для раніше збережених фраз переклад підставиться зі словника.
- Дані зберігаються в локальному сховищі браузера й можуть зникнути після очищення даних сайту. Час від часу роби повну копію ⚙.

## Перевірки та обмеження

Код перевірено `node --check` і за допомогою автоматизованих сценаріїв у Chromium: імпорт стисненого EPUB, навігація кнопкою і симульованим свайпом, 80 карток, SRS, практика та відкриття редактора слова.

Це нове ядро, а не збереження всіх можливостей старого Hub. Тижневий трекер, AI Coach, голосовий запис і складні режими читання свідомо прибрані з інтерфейсу. Тестування на фізичних Android/iPhone і перевірка відновлення даних на реальному сайті ще потрібні.
