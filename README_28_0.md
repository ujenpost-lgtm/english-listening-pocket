# English Pocket 28.0.0 — Simple Learning & Paper Reader

## Безпечне оновлення

1. У поточному застосунку відкрий ⚙ → Data Vault → Повна копія. Збережи отриманий файл поза застосунком та перевір, що він не порожній. Особливо важливі записи збережи окремо.
2. Розпакуй ZIP 28.0.0. У GitHub Desktop відкрий репозиторій `english-listening-pocket` → Repository → Show in Explorer.
3. Скопіюй усі файли з розпакованого архіву безпосередньо в папку репозиторію, погодься на заміну. Не видаляй `.git`.
4. Commit to main → Push origin. Дочекайся оновлення GitHub Pages.
5. Перевір https://ujenpost-lgtm.github.io/english-listening-pocket/version.txt (English Pocket 28.0.0), потім відкрий застосунок. Не очищай дані сайту й не видаляй PWA: це може стерти твої книги та прогрес.

## Слова

- **Вчити**: звичайний урок нових карток. Можна відкрити «Мої картки» для редагування та імпорту.
- **Повторювати**: до шести вже вивчених карток. Спочатку прострочені за розкладом, далі складні/давно не повторені. Помилки та підказки дають одну додаткову спробу наприкінці. Черга і результати зберігаються на пристрої. Це не заміна повного курсу, а коротке сфокусоване заняття.
- **Історії**: 18 варіантів із шести тематичних шаблонів A2–B1; читання, прослуховування без тексту (голос пристрою), 3 питання, корисні фрази, короткий письмовий переказ. Вправи з пропусками використовують тільки твої вивчені картки, якщо вони трапляються в тексті. Наступна історія відкривається після правильних відповідей та переказу. Можна вибрати іншу історію в списку. Генератор шаблонний і локальний, не є нескінченним AI-генератором.
- Старі модулі не видалені: ⚙ → Навчальний інтерфейс → Показувати додаткові інструменти. Історії курсу й Living Stories доступні також у «Інші історії».

## Читання

- Збережено бібліотеку EPUB та налаштування читання. Книжковий фон, сепія та нічний варіант; 3D-гортання — CSS-імітація, не фізична модель паперу.
- Натисни на слово; кнопки «Слово», «Фраза», «Речення» змінюють обсяг виділення. «‹ + слово» та «+ слово ›» розширюють фрагмент. У режимі фрази також можна вибрати останнє слово. «Ще» містить копіювання й збереження перевіреного перекладу.
- Локальний словник і пам'ять перекладів перевіряються першими. «Онлайн» надсилає вибраний фрагмент MyMemory. Перший запит потребує явного дозволу в панелі. Надалі повторного діалогу немає. Дозвіл можна відкликати через ⚙ → Онлайн-переклад у читалці.
- Онлайн-переклад потребує мережі, залежить від доступності та обмежень MyMemory. Не надсилай приватний текст. Локальна модель перекладу залежить від підтримки браузера; універсальний якісний офлайн-переклад речень не гарантований.

## Перевірки та обмеження

Перевірено синтаксис JavaScript, запуск ізольованої копії Chromium із тестовим сховищем, чергу повторень, SRS-помилки, переходи між історіями, вибір слова/фрази/речення, одноразовий дозвіл та повторний запит із модельованим онлайн-перекладачем, гортання тестової книги. Це не тест на фізичному телефоні, з реальною IndexedDB, мережевим MyMemory чи живим GitHub Pages. Після оновлення перевір власну бібліотеку, прогрес, голос, переклад і жести на телефоні. Дані різних пристроїв не синхронізуються автоматично.
