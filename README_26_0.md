# English Pocket 26.0.0 — Personal English Coach & Data Vault

## Головне

Один реліз, без нових головних вкладок («Читати», «Слова», «Відео»):

- **Data Vault** у ⚙: автоматичний локальний знімок навчальних даних і книг при першому запуску/раз на день (якщо сховище браузера доступне), вручну до трьох останніх знімків, доповнення або явний повний відкат, а також **повний JSON-архів** із книгами, локальними ключами, аудіозаписами й установленим словником StarDict. На HTTPS контрольна сума SHA-256 перевіряє цілісність повного архіву. Без хмарного сервера. Знімки не захищають від очищення даних браузера, тому зовнішні файли резервних копій обов'язкові.
- **English Coach** у «Слова»: рекомендація за справжніми помилками, слабкою навичкою та розкладом SRS. Не додає невивчених карток. Створює завдання через наявний механізм перевірки, який записує помилки.
- **B1 Readiness**: короткі завдання на читання, слухання, письмо та мовлення із самоперевіркою. Немає автоматичного присвоєння CEFR B1.
- **Reader Pro**: персональна пам'ять підтверджених перекладів — після явного натискання «Запам'ятати переклад». Є режим читання без відволікань. Наявне виділення «слово / фраза / речення» залишається. Незнайомі речення без підтримуваного перекладацького рушія не видаються за повноцінно перекладені офлайн.
- **Video Detective** в «Відео»: нотатки до конкретного відео, оригінальні timestamps, завдання на розуміння, тест тільки з вивчених карток цього відео, власний speaking-переказ. Без завантаження чужих субтитрів або закритих матеріалів Vanessa.
- **Speaking Coach** у «Слова»: п'ять коротких життєвих ситуацій (співбесіда, квартира, лікар, магазин, колеги); прослуховування питання і запис відповіді через вже існуючий Speaking Studio. Без штучної оцінки вимови.
- **Story Workshop + РОТАЦІЯ**: сім оригінальних історій із нашої навчальної програми. На екрані одна поточна історія; перехід до наступної відбувається після натискання «Завершив → нова історія» або вручну. Прогрес кожної історії зберігається окремо. Власний попередній текст можна повернути. Поглиблені запитання, переказ і альтернативне завершення.

## Дані та сумісність

Ключі попереднього сховища не перейменовано. Механізм `device2511.js` зберігає зв'язок з активним особистим сховищем пристрою (зокрема після переходу з 25.1). Немає автоматичної синхронізації між пристроями. Власні книги, аудіо й словник залишаються локальними.

**Важливо:** повний архів із аудіо може бути великим. Обмеження експорту — приблизно 140 МБ, імпорту — 150 МБ. Перед оновленням рекомендовано завантажити файл резервної копії і переконатися, що він дійсно є у «Завантаженнях». Відкат зі знімка відновлює слова, прогрес та книги, але не аудіофайли й словник; для них потрібен повний архів. Стан PWA/IndexedDB на конкретних мобільних пристроях потребує перевірки після встановлення.

## Тестування

- `node --check` для всіх JavaScript-файлів;
- завантаження повного інтерфейсу в ізольованому Chromium з імітованим локальним/IndexedDB сховищем;
- ротація історій, повернення до попереднього тексту, ізоляція прогресу;
- адаптивна рекомендація зі справжньої вивченої картки;
- експорт навчальних даних, книги й аудіоблобу, безпечне доповнення та явний відкат;
- перевірка включення нових модулів до HTML, PWA cache, маніфесту та ZIP.

Реальний мікрофон, плеєр YouTube, мобільне IndexedDB і онлайн-перекладач у цих тестах не перевірені.
