# English Pocket 25.0.0 — Personal Fluency Loop

**Головна мета:** перейти від упізнавання англійської до самостійного використання; без четвертої вкладки, без платного AI та без автоматичної ротації історій.

## Що нового

### 1. English Brain — облік трьох навичок

- Пригадування (recall), розуміння на слух (listening) і використання у реченні (usage) тепер мають окрему історію доказових спроб `ep25Brain.events` **всередині картки**.
- Нове поле не замінює стару SRS, `ep202Focus`, `ep203Skills` чи історію помилок: воно доповнює їх. Старі картки продовжують працювати.
- Одна оцінена спроба додає один запис у новий журнал; успіх із підказкою не рахується як самостійний.
- Для індикатора «підтверджено» потрібні щонайменше 3 самостійні правильні відповіді, щонайменше у 2 окремі дні, без помилок серед останніх 8 спроб відповідної навички. Це внутрішній орієнтир, не сертифікат CEFR.
- Індикатори спершу можуть бути нульовими: старі навчальні результати зберігаються, але їх не «домальовуємо» до нових показників заднім числом.

### 2. One Phrase Journey — одна фраза, кілька навичок

**Слова → Навчання → Додаткова практика → Шлях однієї фрази**.

- Обери вже вивчену картку.
- Подивись її прогрес за трьома навичками, джерело книги та збережені моменти з YouTube.
- Натисни «Практикувати цю фразу» для пригадування, аудіо та власного речення; тільки справжня картка й її власний приклад, без випадкової лексики.

### 3. Speaking Studio

**Слова → Навчання → Додаткова практика → Speaking Studio** або **Відео → Відео → Слова → Мовлення**.

- Обери запитання або перейди до питання з поточного модуля курсу.
- **Записати** запитує дозвіл на мікрофон, **Зупинити** завершує запис (до 2 хвилин).
- Прослухай запис, збережи його в окрему локальну IndexedDB або завантаж файлом. Ніяких балів за вимову без достовірного аналізу.
- Додаток не надсилає аудіозапис на сервер. **УВАГА: аудіозаписи не входять до звичайної JSON-копії!** Їх треба експортувати індивідуально. Видалення даних сайту зітре локальні аудіозаписи.
- **Диктовка** (коли браузер її підтримує) працює тільки після окремого підтвердження. Деякі браузери передають голос для розпізнавання на свої сервери. Текст диктовки — не оцінка вимови.

### 4. Story Mastery — одна активна історія

**Слова → Навчання → Історії → Поглиблена робота з цією історією**.

- Усний переказ без підглядання, перефразування думки та альтернативний фінал.
- Власні відповіді зберігаються за ID історії (`elp-25-story-deep`).
- Текст не змінюється автоматично. Перехід на нову історію, як і раніше, можливий лише за твоїм підтвердженням.
- Відповіді не отримують автоматичної оцінки граматики.

### 5. Video → Vocabulary → Speaking

**Відео → Відео → Слова → Мовлення**.

- Переглядай збережені з відео фрази й часові позначки, що вже пройшли навчання.
- Перейди до тренування конкретної вивченої фрази.
- Відкрий Speaking Studio із запитанням поточного модуля. Якщо є вивчені фрази з відеоблокнота, вони пропонуються як підказки для власної відповіді.
- Боб і всі додані канали не видаляються. YouTube-субтитри не копіюються.

### 6. Reader Translate 2.0

- Залишено безконфліктний вибір: натискання слова → «Слово»/«Фраза»/«Речення», фраза через два натискання.
- Додано явне джерело перекладу: особистий словник, офлайн-словник, кеш, машинний переклад, словникові підказки. Для відомих багатослівних виразів читалка може запропонувати перекласти саме фразу.
- **Не змінювали** принцип приватності: довільний текст надсилається онлайн лише після підтвердження. Локальна модель речень залежить від можливостей браузера. Кеш і великий StarDict зі старих версій залишаються.
- Читацька 3D-анімація 24.3 та виправлення виділення 24.3.1 збережені.

### 7. Progress та Reliability

- **Слова → Додаткова практика → Мій прогрес:** окремі навички, складні фрази й тижнева перевірка. Без XP та штучного присвоєння B1.
- **⚙ → Перевірка застосунку:** локальні технічні самотести без зміни даних.
- Підпис, manifest, version.txt та service-worker-кеш узгоджені на **25.0.0**.

## Чого тут немає

- Жодного автоматичного AI-оцінювання граматики та вимови.
- Жодного гарантованого повного офлайн-перекладу довільних речень на всіх телефонах.
- Жодного автоматичного завантаження приватних платних уроків, YouTube-субтитрів чи нового словника без твоєї дії.
- Жодної нової головної вкладки.

## Сумісність і перевірки

- Новий облік зберігається у картках і потрапляє до повної JSON-копії. Дані тижневої перевірки та поглибленої історії теж входять в експорт і підтримуються імпортом з 25.0.0.
- Мікрофон потребує безпечного походження HTTPS. Запис та диктовка можуть залежати від телефона й браузера.
- Тести проводилися в ізольованому Chromium: ініціалізація, відбір тільки вивчених карток, однократний лог, облік підказки, вправи з фразою, збереження розгорнутої історії, контекстна пропозиція перекладу, симульована аудіозаписувальна сесія. **Реальний IndexedDB, фізичний мікрофон, YouTube та MyMemory не тестувалися в цьому середовищі.**

2. Розпакуй ZIP; копіюй **файли всередині**, а не папку чи сам ZIP.
3. **GitHub Desktop → Repository → Show in Explorer**; встав нові файли поверх старих, не видаляючи `.git`.
4. **Commit to main → Push origin**.
5. Перевір `https://ujenpost-lgtm.github.io/english-listening-pocket/version.txt`: має бути `English Pocket 25.0.0`.
