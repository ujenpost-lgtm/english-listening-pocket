# English Pocket 26.1.0 — UTalk Navi Bridge

## Що додано

**Читати → UTalk Navi** — компактний згорнутий блок. За бажанням відкриває Telegram-бота [@utalk_navi_bot](https://t.me/utalk_navi_bot). Це пряме зовнішнє посилання, а не вбудований чат.

1. Відкрий бот і обери новину для практики.
2. Скопіюй уривок англійською або підготуй власний конспект; не копіюй матеріал, якщо немає дозволу на його збереження.
3. У English Pocket відкрий **Читати → UTalk Navi → Додати текст новини**, введи назву і встав текст.
4. Новина зберігається **в бібліотеці цього пристрою** як звичайний текст для офлайн-читання, перекладу слів, фраз та речень і додавання власних карток.
5. У читалці для такої новини відкрий **☰ → Завдання до новини**. Напиши коротку головну думку й власну реакцію англійською. Нотатки зберігаються разом із новиною, їх можна змінювати.

## Чого немає

- **Немає прямого підключення до Telegram.** Бот є стороннім продуктом, підтвердженого публічного API для читання його навчальних повідомлень не виявлено.
- English Pocket **не має доступу до Telegram-акаунта, контактів, повідомлень чи токенів**.
- Не імпортує повідомлення, вправи або результати бота автоматично; не видає свої вправи за матеріали UTalk Navi.
- Зовнішній бот потребує інтернету; **імпортована новина доступна офлайн** після збереження.
- Записані нотатки не є автоматично оціненим тестом. Лише фрази, які користувач окремо вивчив, потрапляють у додаткову практику.

## Приватність і дані

- Під час імпорту текст не надсилається до розробників English Pocket чи інших серверів.
- Зберігання використовує ту саму локальну IndexedDB, що й книги; дані різних пристроїв залишаються незалежними.
- **Data Vault → Повна копія** включає імпортовані новини й нотатки разом з іншими книгами.
- Не очищуй дані браузера без перевіреної резервної копії.

Зроби повну резервну копію через Data Vault та перевір її наявність у «Завантаженнях». Розпакуй архів релізу, скопіюй усі файли поверх наявної папки GitHub Desktop, виконай **Commit to main → Push origin**. Перевір `version.txt` — має показувати `English Pocket 26.1.0`.

## Тестування

- Автоматично перевірено синтаксис усіх JavaScript-файлів та наявність файлів кешу PWA.
- В ізольованому Chromium із тестовим сховищем перевірено імпорт, захист від дублювання, збереження й повторне відкриття нотаток та приховування кнопки UTalk у звичайних книгах.
- Реальне перенесення даних через IndexedDB, відкриття бота на телефоні, поведінку PWA і резервне копіювання на фізичному пристрої **потрібно перевірити після встановлення**.
