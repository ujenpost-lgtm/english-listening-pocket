# English Pocket 24.1.0 — Conversation Lab

Цільове оновлення 24.0.1. Новий компактний блок у «Відео», без нової вкладки.

## Оновлення
1. У старому застосунку: ⚙ → Зберегти все.
2. Розпакувати ZIP, у GitHub Desktop: Repository → Show in Explorer.
3. Скопіювати вміст ZIP поверх файлів репозиторію (не видаляти .git).
4. Commit to main → Push origin. Дочекатися успішного GitHub Pages deployment.
5. Перевірити https://ujenpost-lgtm.github.io/english-listening-pocket/version.txt — English Pocket 24.1.0.
6. Відкрити https://ujenpost-lgtm.github.io/english-listening-pocket/ . Не очищати дані сайту; якщо кеш старий, закрити всі вікна застосунку і відкрити знову.

## Conversation Lab
Відео → Conversation Lab · Daily Routine. Чотири етапи, збереження локального прогресу.
- Watch: обери перше відкрите відео Vanessa (Think and Speak: your daily routine), переглянь фрагмент двічі, запиши основну думку й дві деталі. Друге відео — складніший додатковий матеріал.
- Study: п'ять оригінальних тематичних фраз, українські значення, приклади, Present Simple і коротка вправа на вимову. Зберігай картки вручну. Наявні переклади не перезаписуються. Нові картки пройди у «Слова → Навчання».
- Quiz: лише вже вивчені картки модуля. Використовується існуючий механізм тесту 24.0.1 з підказками, фіксацією помилок і пріоритетом складних карток у подальших повтореннях. Після тесту доступний новий тест вручну.
- Speak: відкрий авторську історію A Morning That Changed My Day. Лише після підтвердження вона стає єдиною активною історією в «Слова». Попередній текст і його прогрес зберігаються для повернення. Кнопка повернення розташована внизу історії. Розкажи вголос 60–90 секунд, збережи нотатки й самоперевірку. Зразок доступний після розкриття.
- Повторити модуль: очищає тільки відповіді Conversation Lab, не слова, SRS та історію.

## Джерела та обмеження
Методика: https://speakenglishwithvanessa.com/fluency/ (публічний опис Conversation Breakdown Method).
Відкриті відео: https://www.youtube.com/watch?v=nnDVoc5GwSc та https://www.youtube.com/watch?v=X99fpJ2HB0A .
Фрази, історія, приклади, завдання написані для English Pocket. Це не транскрипти, не матеріали платного курсу, не офіційний курс Vanessa. Озвучення використовує голос пристрою. Відео відкриваються на YouTube; інтернет потрібен для перегляду. Speaking і розуміння відео — самоперевірка, без автоматичної оцінки вимови або змісту. Запис мікрофона не додано.

## Тести
У Chromium з інлайновим HTML/JS та імітованим localStorage перевірено фінальний номер у footer, відкриття модуля, збереження Watch, додавання нової картки та виключення її з тесту, помилку для вивченої картки, стан focus, активацію і повернення історії. Помилок JS не зафіксовано. Реальні service worker, IndexedDB, фізичний телефон, голос та GitHub deployment не перевірені в цьому тесті.
