# English Pocket 28.1.0 — Video Focus

## Встановлення
1. У поточній версії на кожному пристрої створи **⚙ → Data Vault → Повна копія**. Збережи файл окремо.
2. Розпакуй ZIP 28.1.0. GitHub Desktop → Repository → Show in Explorer. Скопіюй усі файли поверх старих у корені репозиторію (не видаляй `.git`).
3. Commit to main → Push origin. Перевір після публікації `https://ujenpost-lgtm.github.io/english-listening-pocket/version.txt`: має бути English Pocket 28.1.0.
4. На тому самому пристрої, у тому самому браузері відкрий застосунок. Не очищуй дані сайту. Перевір свої книги, картки, попередні уроки та нотатки.

## Відео: три режими
- **Заняття**: один рекомендований урок (Боб із рівня A2 або незавершене відео). Позиція і етап зберігаються. Після завершення можна повернутися до головного екрана відео, щоб отримати наступну рекомендацію.
- **Відеотека**: пошук, джерела, останні відео, 6 улюблених каналів, власні YouTube-посилання та збережені фрази з часовими позначками. Каталог показує по 6 матеріалів за раз. Зовнішні матеріали British Council, VOA тощо відкриваються на сайті джерела через окремий мініурок.
- **Мій курс**: 7 наявних модулів, їхні записи й історії залишилися.

## Ефективний цикл
1. У «Перегляді» натисни «Дивитися тут» або YouTube. Візьми 3–5 хвилин ролика. Прослухай без субтитрів; коротко занотуй, що зрозумів. Повтори з англійськими субтитрами або ще раз без них, якщо субтитрів немає. Познач обидва проходи. Можна повторити останні 15 секунд чи встановити межі фрагмента.
2. За бажанням збережи 2–3 фрази з українським значенням і часом. Є пошук значення в локальному словнику. Нові картки потрапляють у «Вчити», а не в диктант.
3. «До закріплення»: запиши основну думку, дві деталі, порівняй із першою спробою, вибери самооцінку. «Завершити заняття» зберігає проходження. Це самооцінка, не автоматична перевірка змісту відео чи рівня CEFR.
4. За бажанням розгорни «Практика фраз»: пройди навчання нових карток або слуховий диктант із уже вивчених фраз саме цього відео. Тест використовує системний голос, а не звук із YouTube. Помилкові фрази повертаються наприкінці один раз. Позиція тесту та результат зберігаються. Усна відповідь відкриває Speaking Studio.

## Дані й обмеження
- Нові поля зберігаються в наявному ключі `elp-243-video-study`. Data Vault експортує `elp-*` ключі; навчальні записи інших розділів не мігрують і не видаляються.
- Старі інструменти можна повернути: ⚙ → Відео · вигляд → Показувати старі відеоінструменти. Попередні записи нотаток, відео й курсу залишаються. Для YouTube-уроків підтягуються доступні попередні нотатки й позначки з Video Detective та старого відеомаршруту.
- Інтернет потрібен для відео. Вбудовування залежить від дозволів YouTube та автора. Якщо не працює, відкрий ролик за кнопкою YouTube. Позиція автоматично фіксується у вбудованому плеєрі; для зовнішнього перегляду час фрази вводь вручну. Автоматичного отримання субтитрів і перевірки вмісту ролика немає.
- Два пристрої залишаються незалежними. Не імпортуй чужу копію. Читалка та основні режими «Слів» не змінені.

## Перевірки
Ізольований Chromium, мобільний viewport 390×844, імітовані localStorage/IndexedDB та YouTube-плеєр: запуск, три режими, зовнішній мініурок, два проходи, самооцінка, додавання фрази з часовою позначкою, відсів невивченої картки, повтор помилки та завершення тесту, 6 каналів, курс. Справжній YouTube, мікрофон, IndexedDB, встановлення та кеш PWA на телефоні не перевірено. JavaScript перевірено `node --check`, пакет — `unzip -t`.
